# PerfectDay AI｜完美金鹰·假日商圈一体化随行助手

**商圈已经打通，PerfectDay AI 让体验也真正打通。**

Concept-to-Pilot 场景验证型 MVP，以 Journey Maintenance 为核心：AI理解用户需求，确定性系统维护正在发生的消费旅程。它不是把假日广场和完美金鹰·石岐万象汇做成两份攻略，而是把已经物理连通、业态互补的一片商圈，组织成一条可以继续、可以调整的行程。

一个移动端优先的商圈半日行程规划 PWA。首个 MVP 聚焦 **中山 · 完美金鹰·假日商圈**。用户可以用一句话表达同行人、时间、预算和偏好，系统将阅读、咖啡、餐饮、购物、亲子与生活方式等互补内容组合成路线；下雨、走累、餐厅排队或时间变化后，只重排未完成部分，保留已经发生的行程。

## 百炼已接入，只需填写 Key

在 Vercel 项目的 **Settings → Environment Variables** 添加 `DASHSCOPE_API_KEY`，值为百炼 **华北2（北京）** 地域的模型 API Key，勾选 Production，保存并重新部署。

接口地址与 `qwen-plus` 已在代码中设为默认值，其余参数不用填。无需创建百炼应用或填写 App ID。完整操作与排错见 [`docs/BAILIAN_SETUP.md`](docs/BAILIAN_SETUP.md)。

首页填写文字后点击“生成行程”，百炼解析自然语言、偏好与排除条件，现有规划器生成路线。未配置 Key、调用失败或触发应用侧防刷限制时仍可使用本地解析/基础规划；行程页显示实际采用的模式。翻页和调整行程不会重复调用模型。应用侧限流只作轻量保护，公开演示前仍应在百炼账户侧设置可接受的额度上限。

## 当前版本：MVP v0.5 · 一体化商圈随行助手

1. **首页**：自然语言 + 约会、朋友、家人、独处 4 个主场景 + 时间、预算与步行偏好；强调“互补业态一起规划、途中只重排未完成部分”；保留快捷示例与 PWA 添加到主屏幕提示，最近行程不作为首页主入口。
2. **行程页**：优先展示“本次为你考虑”的结构化需求标签、下一站、地图与完成/跳过操作；后续时间线、余额、历史记录和进度分享分层呈现；支持撤销上一步。
3. **途中调整**：手动设置所在商场、剩余分钟、人均余额与下一段开始时间；组合雨天、少走路、节省预算与用餐排队条件，即时预览后续路线与移除原因，保存后可撤销。用餐排队时优先替换为同商场、已核验的真实餐饮候选；没有合适候选时才使用现场自选兜底。
4. **商圈指南**：围绕“从物理连通到体验连通”解释一体化商圈，保留地点搜索、商场筛选、公开来源、查阅日期与到店提醒；不再承载比赛 Case 或演示入口。

完成记录使用有版本的URL状态快照；刷新可继续，分享包含需求文字与进度。余额按预计时长/消费扣减，可手动校正。已完成记录不参与重排，保存移除的候选不会自动复活。无需登录或数据库。

本设备的最近行程保存在浏览器本地，撤销记录仅保存在当前标签页。关闭存储权限时，仍可通过进度链接继续。即时预览在本地计算，不会重复调用百炼；保存前可还原修改，已保存调整只能撤销上一步。界面提供加载、错误重试、空结果恢复、键盘焦点与减少动画支持。

本版更正DAKA公开地址为1F层2216，撤下缺少本次资料支撑的精确铺位；雨天优先单一商场，不推定所有连通路径全程遮雨。博雅书店的浏览不预设购书消费。

参赛说明与演示脚本见 [docs/COMPETITION.md](docs/COMPETITION.md)。这是可运行原型，没有开展实地走访、真实用户试用或商圈合作；自动化测试与演示不代表市场效果。

## 技术策略

- Next.js 16 + React 19 + TypeScript
- 纯 CSS 设计系统，减少依赖

## 产品原则

- **一体化商圈，而不是两份攻略**：围绕一片已经连通、业态互补的商圈组织行程。
- **三步内生成路线**：场景、时长、预算/步行偏好足够完成规划。
- **结果优先于聊天**：用户拿到的是可执行时间线，不是一大段 AI 文案。
- **变化只改未来**：已完成部分保留，雨天、排队、走累或时间变化只处理未完成行程。
- **真实性优先**：地点要有来源，过期商户从推荐池移除。
- **确定性优先**：AI 增强需求理解，不成为系统能否使用的前提。
- **可选模型调用**：本地规划无需模型费用；配置 Key 后的调用按百炼账户权益和计费规则处理。
- **逐层增强**：只有用户体验真的需要时，才加入数据库、地图 SDK 或模型 API。

详细产品方案见 [`docs/PRD.md`](docs/PRD.md)，地点核验记录见 [`docs/DATA_SOURCES.md`](docs/DATA_SOURCES.md)。

## 使用边界

消费、停留和步行均为估算，营业、票价、实时排队、车位与精确无障碍通道未接入。公开资料查阅时间不等于现场核验。地图链接使用高德关键词搜索。

多个连通口已启用，但当前项目不把“已连通”进一步推断成“所有路径全程遮雨、无台阶或所有室内动线已核实”。下一步可维护更多经过核对的地点与设施资料；授权商圈数据接入属于后续设想，不是已达成合作。
