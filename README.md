# PerfectDay AI

一个移动端优先的商圈半日行程规划 PWA。首个 MVP 聚焦 **中山 · 金鹰亚洲 × 假日广场**，目标不是做复杂的“AI 展示项目”，而是让用户快速得到一条真的可以照着走的路线。

## MVP 产品范围

只做 3 个核心页面：

1. **首页 / 输入需求**：自然语言 + 场景 + 时长 + 预算 + 步行偏好。
2. **行程页 / 查看路线**：时间线、预计消费、预计步行、每站导航。
3. **动态调整 / 重新规划**：下雨、少走路、预算减少、餐厅排队时重排必要部分。

暂不做：登录注册、会员体系、数据库后台、复杂地图、室内导航、实时排队、多 Agent、支付与社区。

## 技术策略

- Next.js 16 + React 19 + TypeScript
- 纯 CSS 设计系统，减少依赖
- 本地公共点位数据，暂不依赖数据库
- 规则式 Planner，确保没有 AI API 也可用
- 导航按钮直接打开高德 URI，不使用高德 JS API Key
- `app/manifest.ts` 提供 PWA 基础能力
- Vercel 免费部署优先

## 页面

- `/` 首页

- `/adjust` 动态调整

## PRD 核心原则

- **三步内生成路线**：场景、时长、预算/步行偏好足够完成规划。
- **结果优先于聊天**：用户拿到的是可执行时间线，不是一大段 AI 文案。
- **确定性优先**：路线先由规则生成，后续 AI 只负责理解自然语言和润色理由。
- **0 元 MVP**：不引入必须付费或绑卡的基础能力。
- **逐层增强**：真实商户数据 → AI 解析 → 可选地图增强，任何一层失败都不影响基础路线功能。
