## 数据维护原则

1. 优先使用品牌官方门店页、高德门店页、商场官方/权威本地媒体。
2. 不因为旧文章曾经出现过某品牌，就默认门店仍营业。
3. 不展示未经核验的“实时排队”“库存”“精确消费价”。
4. 没有地图 API 时，导航使用高德 URI 的关键词搜索，不伪造精确室内导航。
5. 商户规模扩大前继续使用本地 TypeScript 数据文件；只有维护成本明显上升时才迁移数据库。
