# PerfectDay AI 比赛总说明

版本：2026-09-09冻结版。名称：PerfectDay AI｜双商圈随行助手。

## 唯一主线

Concept-to-Pilot 场景验证型 MVP：把出发前推荐，变成逛街途中持续决策。核心是Journey Maintenance，即维护一条正在发生、持续变化的消费旅程。

AI理解 → 可信数据 → 确定性约束 → 有状态行程 → 动态重排。

当前完成核心交互和技术机制验证，未开展真实用户试用、正式商圈合作或市场效果验证。公开资料不等于实地核验。

## 当前产品

首页四场景、三个快捷示例、PWA添加提示；Trip保留“本次为你考虑”、下一站/地图/完成/重排；Adjust仅改未完成部分，用餐排队先同商场实名候选，缺失才现场自选；Guide只做概况、目录与来源；最近行程为低调入口。无案例中心、会员支付或实时排队。

## 评审可验证的证据

可直接打开生产网站体验固定朋友路线，完成前两站，再用“用餐排队”把大家乐换为味千。两者均有分店级公开页面，历史保持不变。完整输入、预算和步行设置见Demo脚本。测试和演示证明机制可运行，不代表消费者满意度或商圈收入效果。

## 试点请求

希望获得官方商户、铺位及服务设施数据、资料维护联系人和一个小范围入口。建议7天试点是以授权、数据与人员准备就绪为前提的工作安排，未开展正式合作。后续以路线生成率、地图打开率、途中重排率、重排后继续行程比例、资料更新率作为建议试点指标，先建立基线，再决定目标。

## 冻结规则

仅修复演示阻断、明显移动端问题、错误文案/地点/链接、严重可访问性与CI问题。保持当前架构和19个地点样本规模。禁止虚构用户、走访、签约、GMV或实时能力。比赛日期/提交要求以主办方当期通知为准；8月18日启幕仪式报道与用户提供的8月24日征集发布不是同一个时间节点。
