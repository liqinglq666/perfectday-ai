## v0.3 数据原则

1. 核心推荐池控制在少量高价值地点，不追求数量。
2. 优先品牌官方、地图当前地点页、政府/权威本地媒体。
3. 不展示实时排队、实时库存、实时价格。
4. 不能确认精确店号时宁可只写商场/楼层，不伪造精确位置。
5. 已确认闭店的品牌立即退出推荐池。
